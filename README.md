# prototypes

Public static HTML prototypes hosted via GitHub Pages.

Live index: https://michalceo.github.io/prototypes/

Each prototype lives in its own folder with an `index.html`. Visit the index URL for the full list.

## Conventions
- One folder per prototype (kebab-case slug)
- Each folder contains `index.html` and any required assets
- No secrets, no source-project files, only browser-shippable static files
